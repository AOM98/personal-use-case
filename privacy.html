Personal Use Case

Privacy policy

Personal Use Case is a private-use application that uses Google services to store and recover owner-selected data.

Data accessed and purpose

The requested permissions allow reading, creating, changing, and deleting files throughout the authorized Google account's file storage. The app uses this access to store, restore, verify, and manage encrypted backup copies. It is configured to process its backup data rather than unrelated account files.

The owner chooses the data to back up. Backup contents are encrypted before upload and stored using Google services.

Credentials and storage

The app retains Google authorization credentials to perform authorized backup operations. It uses these credentials only for the functions described here. This website does not collect or store those credentials or backup contents.

Sharing and use

Google services provide backup storage. The app does not sell Google user data, use it for advertising, or share it with other parties. Its use of Google user data is limited to the backup functions described here and complies with the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The owner controls backup retention and deletion. Access can be revoked through the Google Account's third-party connections settings. Revoking access stops future authorized operations; it does not automatically erase stored copies. The owner can delete those copies directly from the connected Google service.

This website

These information pages contain no forms, application analytics, or cookies added by Personal Use Case. The website hosting provider may process ordinary web request information under its own policies.
